# 表情包（biaoqingbao）· DeepSeek Harness 插件

让 DeepSeek Harness 里的助手学会用表情包表达自己的情绪与语气。

一句话介绍它：**这是一个养成系表情包插件**。图库由你自己喂，助手通过识图、标签、语义检索和你的反馈，慢慢学会什么样的表情包适合什么样的情绪。

> ⚠️ **先说清楚**：这是一个第三方社区插件，代码完全开源（MIT）。插件会在本地读写图库、标签和偏好；识图、内容分析、学我说话等功能会调用你在 DSH 里配置的模型服务，对应文字或图片可能会发送给模型服务商。安装即代表你信任本插件来源。
>
> 📌 **这是 DSH 的独立移植版，不与 Hana 版强行同步版本号。** 本文按 DSH 版 `v0.3.1` 的实际代码整理。带删除线的功能当前尚未实现，计划在后续版本补齐；没有删除，只是先把状态说清楚哈。

## 这是干什么的？

你有没有想过，让聊天助手在开心的时候发一张「嘿嘿嘿」的猫猫图，在你委屈的时候回你一张「抱抱」？

这个插件就是干这个的：助手可以调用 `express` 工具，按照自己想表达的情绪，从你的图库里挑一张表情包发出来。你也可以直接说「发个委屈的表情包」，让它主动找图。

插件不会附带一套替所有人决定好的图库。第一次安装时图库是空的，表情包从你来；你上传什么、怎么改标签、对哪些图点喜欢或不喜欢，都会影响之后的选择。

## 用之前先知道这些

### 1. 插件不附带任何表情包

第一次打开看到空图库是正常的。你可以：

- 一次选择多张图片批量上传；
- 直接选择文件夹导入；
- 导入 ZIP 图片包；
- 之后继续添加、删除、搜索和整理图片。

当前支持 PNG、JPG、JPEG、GIF、WebP、BMP。单次最多导入 200 张；ZIP 文件最大 50MB，单张图片还会受到 DSH 图片大小限制。

### 2. 完整体验需要三类模型

设置页会分别配置：

- **AI 识图模型**：看懂图片，生成描述、语义描述、情绪、场景和关键词；
- **内容分析模型**：阅读聊天上下文，判断助手此刻是否适合提醒配图，也负责「学我说话」的风格分析；
- **向量模型**：把图片的语义描述转成向量，让字面不同但感觉相近的表达也能找到合适的图。

识图模型和内容分析模型可以从 DSH 已配置的模型里选择，也可以填写 OpenAI 兼容 API；两个区块都带「测试一下」按钮。向量模型目前使用单独的 OpenAI 兼容 `/embeddings` 接口配置，也带连通测试和索引生成。

### 3. DSH 版自动分析由配图频率控制

DSH 版默认的自动观察频率是：日常 50，正事 20。它会先判断对话里有没有值得表达的情绪，再按场景频率决定要不要提醒助手调用 `express`。

如果不想让它自动分析聊天，把日常和正事两档都设为「不配图」。单独关闭「助手配图开关」会阻止最终发图，但关闭自动观察最直接的方式仍然是把两档频率都设为「不配图」。

手动调用 `express` 和图库管理功能不受这个频率影响；助手配图总开关关闭后，`express` 会拒绝发图。

### 4. 模型调用可能产生费用

- 识图模型在手动识图、批量识图和上传后自动识图时使用；
- 内容分析模型在自动观察和「学我说话」时使用；
- 向量模型在生成索引和语义查询时使用。

建议给内容分析选择速度快、价格较低的模型。

### 5. 隐私与联网说明

- 图库、标签、偏好、使用记录和向量索引保存在本地 `${DSH_HOME}/plugin-data/biaoqingbao/`；
- 插件不会把数据上传到作者自己的服务器；
- 自动观察会把相关聊天上下文交给你选择的内容分析模型；
- 「学我说话」会读取 DSH 能访问到的会话中的用户发言，并交给你选择的内容分析模型；
- 识图会把图片和识图提示发送给你选择的视觉模型服务；
- 自定义 API Key 保存在插件本地配置中，设置页只显示脱敏占位符；
- 卸载插件不会主动删除图库数据。

### 6. 方言和学我说话不会改助手人格文件

DSH 版不会写入 Hana 的身份文件或 DSH 助手预设文件。方言和「学我说话」通过 DSH 的提示词注入机制生效：

- 每位助手可以单独选择方言，互相不串台；
- 「加强版」会在部分对话轮次追加方言回响，正事场合自动让路；
- 「学我说话」确认后会覆盖方言口音，随时可以回退上一版；
- 选择「（不选）」或回退风格即可关闭对应效果。

DeepSeek Harness 仍处于开发者预览阶段，插件接口可能随版本演进。

## 它能做什么

### 🗂️ 你的图库，你自己养

本地管理，不需要图床：

- 单张上传、一次多选、整个文件夹、ZIP 图片包；
- 支持 PNG、JPG、JPEG、GIF、WebP、BMP；
- 搜索情绪、场景、关键词和描述；
- 打开单张图片编辑描述、情绪标签、场景标签、关键词和语义描述；
- 删除不想要的图片；
- 上传后可以自动识图，也可以之后手动批量识图；
- 失败或不满意的图片可以打开详情再次识图、手动修改。

当前上传主要按 MIME 类型和大小校验；ZIP 内的图片会额外做内容签名检查。重复图片暂时不会自动去重。

### 🧠 AI 识图：帮你认图

视觉模型会为图片生成：

- 一句话描述；
- 这张图适合在聊天里回复什么的语义描述；
- 情绪标签；
- 场景标签；
- 关键词。

支持单张识图、批量识图和上传后自动识图。没有配置视觉模型时，仍然可以上传图片、搜索和手动编辑标签，只是不能调用识图。

### 🏷️ 标签 + 语义双通道

选图时会综合参考：

- 情绪标签；
- 使用场景；
- 关键词；
- 图片描述；
- 语义描述；
- 向量相似度；
- 你留下的喜欢 / 不喜欢反馈。

标签负责稳定、直观的匹配；向量负责理解「字面不同、感觉相近」的表达。配置向量模型后，识图成功的图片会自动尝试生成语义指纹，也可以在设置页手动生成索引。

如果更换向量模型，旧向量会被视为不兼容，需要重新生成索引。

### 👍 反馈调教：喜欢 / 不喜欢

聊天里的表情卡片下方可以打开反馈按钮：

- **喜欢**：这张图合口味，类似情绪以后更容易选到；
- **不喜欢**：这张图不贴合，类似情绪以后会逐渐少选；
- 同一张图可以重新表达态度，切换方向也会更新偏好；
- 每位 DSH 助手的反馈独立记录，没有单独调教过的助手会沿用全局默认偏好；
- 设置页可以关闭反馈按钮，让聊天卡片只显示图片。

### 💬 和助手聊聊：自然语言修改标签

觉得标签不准时，点「不喜欢」后可以打开「聊聊」入口，直接说明哪里不对，例如：

> 这张图不是生气，更像委屈。
>
> 它适合等回复的时候，不适合吵架。

助手会围绕当前标签和你的反馈多轮沟通。达成共识后，它会给出修改建议，你确认应用后才会写回图库；不满意可以继续聊，不会自动覆盖原标签。

设置页的「最近配图记录」也可以打开同样的聊天入口，回头调教最近发过的图片。

### 👀 自动配图观察器

收到新消息时，插件可以读取一小段会话上下文，让内容分析模型判断助手此刻是否有值得表达的情绪。

判断命中后，插件会给助手一个轻量提醒，由助手自己决定要不要调用：

```js
express({ emotion: '委屈' })
```

它不会替助手强行发送图片。日常和正事使用不同配图频率，每位助手也可以单独设置；插件还会做冷却和会话核对，尽量避免连续轰炸或串到别的窗口。

### 👥 每位助手单独设置

如果 DSH 中存在助手预设，插件会自动把它们列在「每位助手单独设置」里。安装 [小花记忆](https://github.com/moononnn/DeepSeek-Harness-Hanako-Memory) 后，这个功能会直接和助手预设联动：

- 每个助手可以有自己的配图开关；
- 每个助手可以分别设置日常 / 正事配图频率；
- 每个助手可以选择自己的方言；
- 每个助手的喜欢 / 不喜欢偏好独立保存；
- 当前会话会按正在使用的助手预设选择对应配置；
- 没有助手预设时，全局默认设置照常工作。

### 🎭 让助手带上家乡味：方言口音

目前有 9 种方言：东北话、河南话、上海话、粤语、台湾腔、四川话、陕西话、北京话、新疆话。

可以设置全局默认方言，也可以给每位助手单独覆盖。选择「（不选）」即可关闭；打开「加强版」后，部分非正事轮次会追加一小段方言回响。

DSH 版通过系统提示词和消息注入生效，不修改助手人格文件，也不需要把方言内容写进用户自己的设定里。

支持快速分析和深度分析。分析结果先作为草稿展示，你可以编辑后确认；当前风格可以回退到上一版。

## 助手可以调用的工具

除了管理面板，DSH 里的助手还可以使用这些工具：

- `express`：按情绪挑选并发送一张表情包；
- `search_stickers`：按情绪、场景、关键词或描述搜索图库；
- `list_stickers`：查看图库列表；
- `update_sticker_tags`：修改图片描述和标签；
- `report_bad_match`：记录某张图不贴合当前情绪，让之后少选它。

## 第一次使用

1. 安装并启用插件；
2. 重启 `dsh web`，从侧栏打开「表情包」；
3. 上传自己收集、制作或有权使用的图片，也可以选择文件夹或导入 ZIP；
4. 配置 AI 识图模型，为图片生成描述和标签；
5. （可选）配置向量模型，测试连通后生成语义索引；
6. 配置内容分析模型，并设置日常 / 正事配图频率；
7. （可选）在「每位助手单独设置」里为某个助手单独选择开关、频率和方言；
8. （可选）使用「学我说话」，先分析、编辑草稿，再确认使用；
9. 正常聊天，也可以通过 `express`、反馈和标签修改，让图库逐渐贴近你的习惯。

## 安装

推荐先从 GitHub 安装：

```sh
dsh plugin --profile web add github:moononnn/DeepSeek-Harness-biaoqingbao
```

也可以把 GitHub 地址替换成你实际使用的 npm 包名：

```sh
dsh plugin --profile web add <package-name>
```

安装后重启 `dsh web`，侧栏底部应出现「表情包」入口。headless 模式没有管理面板，但助手工具仍可用。

## 数据与隐私

- 图库、偏好、使用记录和向量索引保存在 `${DSH_HOME}/plugin-data/biaoqingbao/`；
- 插件不连接作者自己的服务器，也不附带开发者的聊天记录、图库或 API Key；
- 识图时，图片会发送到你配置的视觉模型服务；
- 自动观察时，相关会话片段会发送到你配置的内容分析模型服务；
- 使用「学我说话」时，采集到的用户发言会发送到你配置的内容分析模型服务；
- 使用自定义 API 时，文字、图片和 Key 会按你的配置直接发送给对应服务商；
- 卸载插件不会主动删除图库数据。

## 兼容性

- 需要 DeepSeek Harness v0.1 rc 系列及 Node.js 20+；
- Web 模式完整支持；
- headless 模式下工具可用，但没有图库管理面板；
- 不依赖其他 dsh 插件：没有助手预设时全局默认照常工作；安装能提供助手预设的插件后，每位助手单独设置自动可用。

- 每位助手单独设置；
